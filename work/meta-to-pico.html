Porting a children's MRI simulator from Quest to Quest + Pico

A small VR MRI simulator for children, originally built for Meta Quest by the software's owners. We were subcontracted to make it run on both Meta Quest and Pico from one project.

Client
The simulator's original developer, via subcontract
My role
Port and platform integration
Stack
Unity · C# · XR Interaction Toolkit
Platforms
Meta Quest + Pico

The job

The simulator was built for Meta Quest only. The owners wanted it on Pico as well, without maintaining two separate projects.

What it covered

  • Engine upgrade. Moved the project to a newer Unity version.
  • Interactions on XR Interaction Toolkit. Replaced the original Meta-specific interactions with XR Interaction Toolkit, so the same interaction code runs on both headsets.
  • Dual-platform builds. Integrated the tooling needed to build the same project for Meta and Pico devices.

Supporting both headsets from one codebase was a recurring need at the studio. Several projects shipped for Meta Quest and Pico together, and I maintained a series of enterprise Pico training modules over several releases.
